# 🌿 হোমিওপ্যাথিক সফটওয়্যার

একটি ওয়েব-ভিত্তিক হোমিওপ্যাথিক প্র্যাকটিস সফটওয়্যার — রেপার্টরি, ম্যাটেরিয়া মেডিকা, কেস টেকিং, রোগী ব্যবস্থাপনা ও বিশ্লেষণ।

## টেকনোলজি
- **ফ্রন্টএন্ড:** React + Vite + Tailwind CSS
- **ব্যাকএন্ড:** Node.js + Express
- **ডেটাবেজ:** SQLite (Node-এর বিল্ট-ইন `node:sqlite`)

## ফোল্ডার
```
server/   → ব্যাকএন্ড (Express API + SQLite)
client/   → ফ্রন্টএন্ড (React)
```

## চালু করার নিয়ম

দুইটি আলাদা টার্মিনাল লাগবে।

**১. ব্যাকএন্ড:**
```bash
cd server
npm install
node db/seed.js     # প্রথমবার — নমুনা ডেটা ঢোকাবে
npm run dev         # http://localhost:4000
```

**২. ফ্রন্টএন্ড:**
```bash
cd client
npm install
npm run dev         # http://localhost:5173
```

ব্রাউজারে **http://localhost:5173** খুলুন। ফ্রন্টএন্ড `/api` কলগুলো স্বয়ংক্রিয়ভাবে ব্যাকএন্ডে পাঠায় (Vite proxy)।
