রেপার্টরি পেজের সার্চ **শুধু রুব্রিক** খুঁজবে; ম্যাটেরিয়া মেডিকা পেজের সার্চ **শুধু ওষুধ** খুঁজবে। আগে রেপার্টরি সার্চে "সম্পর্কিত ওষুধ" (কী-নোট/ক্লিনিক্যাল গদ্য) ফলাফলও আসত — ২০২৬-১১-০২-এ ব্যবহারকারীর নির্দেশে সেটি সরানো হয়েছে।

**Why:** ব্যবহারকারী স্পষ্ট বলেছেন — "রেপার্টরি সার্চ রেপার্টরিতে সীমাবদ্ধ থাকবে। ম্যাটেরিয়া মেডিকার সার্চ ম্যাটেরিয়া মেডিকাতে সীমাবদ্ধ থাকবে।"

**How to apply:** রেপার্টরি সার্চে `searchRemediesProse`/ওষুধ-ফলাফল আবার যোগ করবেন না। ওষুধ-পিকারের (রুব্রিকে ওষুধ লিংক করা) ভেতরের সার্চ আলাদা — সেটি অ্যাডমিনের ডেটা-এন্ট্রি, সেখানে ওষুধ সার্চ থাকবে। বিশ্লেষণের স্কোর টেক্সট-ভাষা নয়, নির্বাচিত রুব্রিক-আইডি + grade দিয়ে হয় — [[project-homeopathy-app]]।
